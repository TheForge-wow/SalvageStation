# Salvage Station

One-click disenchanting built for WoW Forever: see what an item will give you, whether it's worth more sold, and disenchant your bags with one button.

- **Bugs, feedback & test builds:** [The Forge Discord](https://discord.gg/yskDeZjQj7) (run `/salvage debug` in game and paste the report)

## Features
- Disenchant window and compact bar with **possible results** for every item
- Tooltip panel comparing **Disenchant**, **Vendor** and **Auction** value, with a clear verdict
- Learns from your own disenchants and switches to your real results
- Protection: upgrade guard, item level and value protection, gear sets, ignore list
- Safety confirms for Epics, Rare BoE items and valuable items
- Statistics with profit or loss, and a Knowledge view
- Auction house scanner for gear worth more disenchanted than its buyout
- TSM and Auctionator prices, hotkey, minimap button and data bar support

## Commands
| Command | What it does |
|---|---|
| `/salvage` or `/sst` | Open or close the window |
| `/salvage compact` | Switch to the compact bar |
| `/salvage stats` | Open Statistics |
| `/salvage settings` | Open Settings |
| `/salvage auction` | Open the auction scanner |
| `/salvage check` | Run a self-check |
| `/salvage debug` | Open a debug report you can copy and paste into Discord |
